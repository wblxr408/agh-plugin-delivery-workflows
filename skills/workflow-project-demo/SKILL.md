# 参考项目复用与演示

先确定目标用户的一次完整操作，写清真实入口、代表输入、可见结果与交付格式。定位参考项目的具体版本和授权，列出直接复用、需适配和由宿主承担的能力。

先实现一条从输入到结果的主线。用有代表性的新输入通过实际入口操作，并验证一条会影响承诺的边界。实现卡住时定位主线上哪个前提交付不了，再处理对应模块。

交付运行说明、演示路径、版本来源和验证证据。提交外部平台时沿用任务授权与实际表单字段；演示记录区分实测、样例和剩余差项。
