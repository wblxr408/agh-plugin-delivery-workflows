# Skill 定制与打包

用一个代表请求写清触发场景、需要保留的事实、期望产物和当前缺口。定位应调整的触发描述、流程、参考资料或使用入口；核对来源版本和许可。

编写可独立使用的短 SKILL.md，稳定参考按需放入单独文件。公开包只使用可公开的资料与合成示例。需要脚本时写明输入、输出、运行条件和授权；按目标宿主的实际包格式分发。

通过真实入口用代表任务试用，核对触发范围、来源和产物。交付安装方式、调用示例及是否完成实际试用。初次只有桌面推演时，用具体输入和可观察的预期结果说明验证边界。
