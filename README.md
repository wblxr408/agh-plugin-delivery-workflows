# 项目交付与 Skill 定制 · Project Delivery Workflows

复用参考项目完成演示，按代表任务定制和打包 Skill。

在 AGH 市场安装本包后，从「智能体」打开对应入口，也可在会话输入 `$` 选择 Skill。按提示补充任务材料。

- [参考项目复用与演示](skills/workflow-project-demo/SKILL.md) · `workflow-project-demo`。从参考项目提取能力并完成可验证的端到端演示。
  示例：`$workflow-project-demo 请基于参考项目完成这条演示主线；我会提供参考链接、目标入口和代表输入。`
- [Skill 定制与打包](skills/workflow-skill-adaptation/SKILL.md) · `workflow-skill-adaptation`。按代表任务改造通用 Skill，形成可安装和可验证的包。
  示例：`$workflow-skill-adaptation 请按这个真实任务定制 Skill；我会提供技能来源、触发场景、复用边界和预期产物。`

Skill 和 Bundle 随安装提供。文件、模型与工具沿用当前 AGH 会话配置。
